A tiny Node program that writes a single one-line joke (at most 200 characters, no trailing newline) about a meeting that should have been an email to `/output/entry.txt`. The joke is the whole entry: one line, deterministic, byte-identical on every run.

## Run it

```sh
node main.ts
```
